# @rathkit/rte-element

The editor as a custom element, <rk-editor>, for any page or framework: form-associated, with properties, attributes and events.

**Pre-alpha.** Not published yet, and the APIs will change. Part of [Rathkit RTE](https://github.com/rathkit/rte), a rich text editor with zero runtime dependencies. Documentation: <https://rathkit.com>.
