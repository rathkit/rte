# Sample documents

Write these yourself in each source app so every source carries the same content and results can be compared. Keep the text short and fake. Never use real work or personal content.

Write each sample once per app, then copy and paste it into the capture page. Name the sample in the page exactly as below.

## Word and Google Docs (text)

**S1-formatting.** A Heading 1 and a Heading 2. A paragraph with one bold word, one italic word, one underlined word, one struck-through word, one red word, one yellow-highlighted word, and a 20-point word. A superscript and a subscript.

**S2-lists.** A bulleted list with three items, the second having two nested sub-items. A numbered list with three items. A multilevel list with 1, a, i levels (three levels deep). A checklist, if the app has one.

**S3-table.** A 3-column, 4-row table with a bold header row, one cell with a background color, one cell spanning two columns, and one cell containing two paragraphs.

**S4-links-images.** A paragraph with a hyperlink on two words. A small image (any picture you own), inline in a paragraph. A second image on its own line.

**S5-mixed.** A paragraph, then a list, then a table, then another paragraph, copied together in a single selection.

## Excel and Google Sheets (cells)

**X1-cells.** A 4-column, 5-row range with a text header row, numbers, a date, a percentage and a currency value.

**X2-merged-formats.** The same range with a bold header, a colored fill on two cells, a merged cell across two columns, and one cell with a formula (for example =SUM of the numbers above).

**X3-wide-range.** A range about 12 columns wide and 3 rows tall, to test wide-table handling.

## Per app and browser

For each source app, copy in that app and paste into this page in each browser you can reach: Chromium (Chrome or Edge), Firefox, Safari. The web apps (Word and Excel for the web, Google Docs and Sheets, Outlook on the web, SharePoint) matter most. Do the copy and paste in the same browser. For a desktop app, run the capture page in any browser.

Set Source app, Sample, Browser and OS in the page before each paste.
